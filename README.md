#DESCRIPTION :
The main purpose of CHROME-TRACKER is to track and display the amount of time a user spends on each website throughout the day.
It works as a Chrome extension that runs in the background, silently monitoring the user’s active tabs. 
Whenever the user switches to a new website or changes tabs, the extension records the URL and logs the time spent on the previous tab. 
This way, it maintains a timeline of user activity, which can later be reviewed to understand browsing habits.

I used HTML, CSS, and JavaScript to build the extension’s frontend, which is responsible for interacting with the user. 
The backend, written in Python, processes and stores the data received from the extension. 
The communication between the Chrome extension and the backend is done using HTTP requests. 
I used a simple JSON file as a database to store the browsing data in an organized manner.

One of the main things I wanted to achieve through this project was to understand how browser extensions work under the way—how they are structured, how they access browser APIs, and how they communicate with external servers. 
This project helped me understand all of these concepts in a practical way.

The user interface of the extension is simple and clean. It shows a summary of the time spent on each website for the current day. 
Users can easily see where most of their time is going. This data can help people identify distractions and manage their time better online. 
For example, if someone realizes they are spending too much time on social media during work hours, they can take action to reduce it.
